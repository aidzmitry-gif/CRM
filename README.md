# CRM

Модуль **Sales (CRM)** платформы AI-First Business OS: сделки, доска по стадиям, карточка сделки и её наполнение.

## Границы репозитория

**Здесь живут все CRM-блоки:**
- сделки и доска (стадии, drag&drop, создание);
- карточка сделки: позиции номенклатуры (SKU), контакты контрагента (основное лицо), документы (счёт / договор / заказ) с записью в 1С и согласованием договора (human-in-the-loop), омниканальные сообщения;
- KPI «План на сегодня» и план/факт по периодам (день/неделя/месяц/квартал/год);
- Price Engine (история и минимальная цена клиенту);
- панель «Чаты и дела»;
- AI-подмодуль сделки (Итерация 1, за feature-flag, по умолчанию выключен): черновик ответа, резюме, следующий шаг, реакция на входящие сообщения.

**Здесь НЕ живут (отдельные репозитории):**
- **Лиды** — приём, квалификация, распределение, конвертация в сделку (Lead Qualifier & Router). Вынесены коммитами `refactor: лиды вынесены в отдельный репозиторий`. Связка: репозиторий лидов по событию конвертации создаёт сделку здесь (`sales.deal.created`).
- **Тендеры** — воронка тендеров и всё с ней связанное.

## Структура

Код — содержимое модуля `modules/sales/` монорепо (импортирует `core.*`); сам по себе не запускается, подключается к ядру через `ModuleContract` (`module.py`). Папка `migrations/` зарезервирована под миграции модуля.

## Правило коммитов

Новые CRM-блоки коммитим сюда. Любой функционал лидов или тендеров — только в их репозитории; здесь допустимы лишь точки интеграции через события шины.
